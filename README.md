# Arduino Due Servo Control CLI

Прошивка для Arduino Due управляет 32 каналами двух PCA9685 через Serial CLI. Логика управления отделена от драйвера PCA, поэтому её можно проверять с тестовым mock без робота.

## Установка PlatformIO

### Windows — установка через Python

Установите Python 3, затем в PowerShell выполните:

```powershell
py -m pip install --user platformio
py -m platformio --version
```

Если команда `pio` не найдена, добавьте каталог `Scripts` пользовательской установки Python в `PATH` и перезапустите терминал. Узнать базовый каталог Python можно командой `py -m site --user-base`; нужный каталог находится внутри него и называется `Scripts`. До настройки `PATH` команды PlatformIO можно запускать через `py -m platformio`.

Альтернатива — установить Visual Studio Code и расширение **PlatformIO IDE**: оно установит PlatformIO Core и предоставит терминал PlatformIO.

### Linux / macOS

```sh
python3 -m pip install --user platformio
python3 -m platformio --version
```

После установки первый запуск сборки скачает платформу Arduino Due, toolchain и библиотеки проекта.

## Сборка и тесты

Требуется PlatformIO Core:

```sh
pio run -e due
pio test -e native
```

Прошивка собирается для Arduino Due (`atmelsam`, `due`). Native-тесты проверяют логику без подключения платы и записывают команды PWM в mock. На компьютере для native-тестов нужен установленный C++ compiler.

Загрузка и Serial Monitor:

```sh
pio run -e due -t upload
pio device monitor -b 115200
```

## Конфигурация

Аппаратные параметры находятся в `include/config.h`: адреса PCA9685, скорость Serial, частота PWM, ширина импульса и таблица ограничений каждого сервопривода. Стандартная шина Arduino Due — SDA 20 / SCL 21; Arduino Due не позволяет произвольно назначать пины через стандартный `Wire` API.

Значения 500–2500 мкс и диапазон 0–180° — начальные настройки из PRD, а не проверенная калибровка конкретной механики. Перед подключением реальных сервоприводов следует проверить безопасные пределы. Отладочный вывод управляется `DEBUG_ENABLED` и по умолчанию выключен, чтобы не загрязнять машиночитаемый протокол.

## Команды

Команды завершаются `LF` или `CRLF`:

```text
SERVO <id> <angle>
GROUP_CREATE <name> <id> ...
GROUP <name> <angle>
SET <id>:<angle> ...
MOVE <id> <angle> <time_ms>
MOVE_GROUP <name> <angle> <time_ms>
MOVE_SET <time_ms> <id>:<angle> ...
GET <id>
GET_ALL
STATUS
HELP
STOP
```

Логические ID 0–15 соответствуют PCA #1, а 16–31 — PCA #2. Имеются предустановленные группы `RIGHT_HAND` и `LEFT_HAND`; CLI-группы хранятся в фиксированной таблице на 8 групп, до 16 сервоприводов в группе, имя до 15 символов.

`GET` возвращает программно известное положение. При запуске и после `STOP` положение считается `UNKNOWN`, поскольку PCA9685 не измеряет реальный угол. Плавное движение возможно только после задания начальной позиции командой `SERVO`/`SET`.

`STOP` отключает PWM на всех обнаруженных PCA (режим full-off), отменяет запланированные движения и сбрасывает известное программное положение. Реальное поведение сервопривода после снятия PWM зависит от питания и механики.

## Статус проверки

Автоматические native-тесты и сборка прошивки проверяют программную логику. Проверка I²C, фактических импульсов, механических ограничений, движения и физического поведения `STOP` требует подключённой Arduino Due, двух PCA9685 и сервоприводов; эти проверки пока не выполнялись.
